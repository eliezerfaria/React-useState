# React-useState
React project demonstrating the use of the useState Hook

The objective of this project is to demonstrate how the React.js useState Hook works. 
The useState hook in React enables functional components to manage and update local state. It is a fundamental hook for adding stateful logic to functional components, eliminating the need for class components in many scenarios.
In this project, we will work with incrementing values ​​when clicking a button and with real-time updating of a text field.
